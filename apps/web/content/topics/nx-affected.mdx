**Affected** means: look at a git range, see which files changed, walk the [project graph](/blog/project-graph) *upward*, and run the target only on that set.

```bash
pnpm nx affected -t test
pnpm nx affected -t build --base=origin/main --head=HEAD
```

Edit `libs/utils/src/json.ts` → `utils` tests run, and `web` build is affected because the app depends on utils. A change only in `README.md` (if it is not an input) may affect nothing.

In [CI](/blog/continuous-integration), `--base` is usually the target branch of the PR so you do not rebuild every library on every push.
