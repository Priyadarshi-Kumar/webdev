**Yarn Classic** is Yarn **1.x**. It was built as a faster, lockfile-first npm. Layout is a hoisted `node_modules`, same idea as npm.

```bash
yarn              # install
yarn add lodash
yarn add -D vitest
yarn remove lodash
yarn dev          # run script (no "run" needed)
yarn dlx create-vite@latest
```

Lockfile: `yarn.lock`. Workspaces: `"workspaces"` in root `package.json`. Frozen CI: `yarn install --frozen-lockfile`.

If a teammate says “we use Yarn,” ask **1 or Berry**. The debugging story is different.
