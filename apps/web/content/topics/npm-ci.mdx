`npm install` may update `package-lock.json` to satisfy ranges. `npm ci` will **not**. It deletes `node_modules`, requires an existing lockfile, and installs that graph — or fails.

```bash
# local tinkering
npm install

# CI / production image
npm ci
```

```bash
# cousins
yarn install --frozen-lockfile     # Yarn 1
yarn install --immutable           # Yarn Berry
pnpm install --frozen-lockfile     # pnpm
```

If `npm ci` fails, the lockfile is out of date with `package.json`. Fix it locally, commit the lockfile, push again.
