<Term id="virtualisation">Virtualisation</Term> (windowing) keeps the full dataset in memory but only **mounts the rows in the viewport**, plus a small buffer. A spacer (or translated window) makes the scrollbar the height of the whole list.

`memo` on every row does not replace this. Memo skips re-renders; it does not skip the first mount or layout of thousands of nodes.

```tsx
const start = Math.floor(scrollTop / itemHeight);
const count = Math.ceil(viewportHeight / itemHeight) + overscan * 2;
const slice = items.slice(start, start + count);
```

The spacer is `items.length * itemHeight`. Variable-height rows need measured prefix sums instead of division.

The full model — overscan, `ResizeObserver`, infinite scroll vs windowing, grids and tables — is in [list virtualisation](/blog/list-virtualisation). [React Virtuoso](/blog/react-virtuoso) is the library that measures for you.
