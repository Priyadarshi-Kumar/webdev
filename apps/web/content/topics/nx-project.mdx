An **Nx project** is a package in the [monorepo](/blog/monorepo) that Nx can address by name. This repo puts a `project.json` next to each one.

```json
{
  "name": "web",
  "projectType": "application",
  "sourceRoot": "apps/web",
  "implicitDependencies": ["widgets", "utils"],
  "targets": {
    "build": {
      "executor": "nx:run-commands",
      "options": { "command": "pnpm build", "cwd": "apps/web" },
      "outputs": ["{projectRoot}/dist"]
    }
  }
}
```

`nx build web` means “run the `build` target on the project named `web`.” Libraries (`utils`, `widgets`) are projects too.

Related: [Nx](/blog/nx), [Nx monorepo](/blog/nx-monorepo).
