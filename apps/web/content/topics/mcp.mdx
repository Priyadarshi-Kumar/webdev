**MCP** (Model Context Protocol) is how an AI app talks to *other programs* in a standard way: list what they can do, then call those capabilities with JSON.

```txt
you → host (Cursor, Claude, …) → MCP client → MCP server → files / APIs / DB
```

It is not a model. It is not a replacement for REST in your product UI. It is the USB-C of **agent context**: one protocol, many servers.
