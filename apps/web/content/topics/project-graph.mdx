The **project graph** is Nx’s picture of the repo: nodes are [projects](/blog/nx-project), edges are “this one imports that one.”

```txt
web → widgets → components → store
 ↘     ↘ utils → types
   tools
```

Nx builds it from `package.json` dependencies, TypeScript path imports, and `implicitDependencies` in `project.json`.

```bash
pnpm nx graph
pnpm nx show project web --web
```

Task order follows the arrows: `utils` tests can run before `web` build if you ask Nx to respect deps (`^test` as a dependsOn).
