**Yarn Berry** is Yarn **2, 3, 4+**. New config (`.yarnrc.yml`), new constraints, and **Plug’n’Play** unless you opt out.

```yml
# .yarnrc.yml
nodeLinker: node-modules   # optional: behave like Yarn 1 on disk
```

```json
{
  "packageManager": "yarn@4.9.1"
}
```

```bash
corepack enable
yarn install --immutable    # CI
yarn add lodash
yarn why react
```

Corepack reads `packageManager` so everyone runs the same Yarn 4, not a leftover Yarn 1 from `brew`.
