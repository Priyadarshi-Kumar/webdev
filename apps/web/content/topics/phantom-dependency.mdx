A **phantom dependency** is a module your code imports that is **not** in your `package.json`. It is on disk only because a dependency of a dependency was [hoisted](/blog/hoisting).

```ts
// lodash is NOT in your package.json — this can still compile on npm
import { debounce } from "lodash";

export const onResize = debounce(() => {
  window.dispatchEvent(new Event("layout"));
}, 150);
```

On pnpm (and Yarn PnP) you get:

```txt
Error: Cannot find module 'lodash'
```

Fix: declare it.

```bash
pnpm add lodash
```

The error is annoying for a day and cheaper than an outage after someone bumps a nested package.
