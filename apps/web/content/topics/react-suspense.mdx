**Suspense** lets a parent declare “show this spinner until the child is ready.” Children can wait on `lazy()` code-splitting or on <Term id="react-use">`use(promise)`</Term>.

## Code-splitting a heavy child

**Plain English:** Code-splitting a heavy child — definition, example, and where you will see it.

```tsx
import { lazy, Suspense } from "react";

const Editor = lazy(() => import("./Editor"));

export function Notes() {
  return (
    <Suspense fallback={<p>Loading editor…</p>}>
      <Editor />
    </Suspense>
  );
}
```

The browser downloads `Editor` only when `Notes` renders. Until the chunk arrives, users see the fallback — not a blank hole.

## Nested boundaries

**Plain English:** Nested boundaries — definition, example, and where you will see it.

Each boundary catches “wait” from **its** descendants. A slow widget should not block the whole page:

```tsx
export function Dashboard() {
  return (
    <>
      <h1>Dashboard</h1>
      <Suspense fallback={<p>Loading chart…</p>}>
        <Chart />
      </Suspense>
      <Suspense fallback={<p>Loading table…</p>}>
        <Table />
      </Suspense>
    </>
  );
}
```

## Errors are a different boundary

**Plain English:** Errors are a different boundary — definition, example, and where you will see it.

You still need an **error** boundary for failures. Suspense is for “not ready yet,” not for “it threw.”

```tsx
import { Component, type ReactNode } from "react";

class ErrorBoundary extends Component<{ children: ReactNode }, { err: Error | null }> {
  state = { err: null as Error | null };
  static getDerivedStateFromError(err: Error) {
    return { err };
  }
  render() {
    if (this.state.err) return <p>Could not load.</p>;
    return this.props.children;
  }
}
```

Wrap `Suspense` *inside* an error boundary if a rejected promise should show a message instead of crashing the tree.
