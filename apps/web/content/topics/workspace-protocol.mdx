In a [monorepo](/blog/monorepo), an app should depend on a sibling library **by workspace**, not by a published version you might forget to bump.

```json
{
  "name": "web",
  "dependencies": {
    "@webdev/widgets": "workspace:*",
    "react": "^19.2.8"
  }
}
```

`workspace:*` = whatever version is in this repo’s `libs/widgets/package.json`. pnpm links it. `workspace:^` is stricter about the sibling’s version field.

```bash
pnpm --filter web add @webdev/utils --workspace
```

npm/Yarn workspaces also link local packages when the name matches a workspace; pnpm makes the protocol explicit in `package.json`.
