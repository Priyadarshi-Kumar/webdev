`use` (React 19) can unwrap a **Promise** or a Context. For a promise, the component **pauses** until it resolves. A parent [Suspense](/blog/react-suspense) shows a fallback meanwhile.

```tsx
import { Suspense, use } from "react";

const userPromise = fetch("/api/me").then((r) => r.json());

function Profile() {
  const user = use(userPromise);
  return <p>{user.name}</p>;
}

export function Page() {
  return (
    <Suspense fallback={<p>Loading…</p>}>
      <Profile />
    </Suspense>
  );
}
```

Unlike other hooks, `use` **may** sit in `if` / `switch` if the condition is stable for that render. Prefer loading data in a Server Component when you can.
