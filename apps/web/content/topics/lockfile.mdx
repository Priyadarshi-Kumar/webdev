`package.json` says “React 19-something.” The **lockfile** says “React 19.2.8, plus scheduler 0.26.0, plus these integrity hashes.”

```bash
package-lock.json   # npm
yarn.lock           # Yarn
pnpm-lock.yaml      # pnpm
```

Commit it. Do not keep two. If Alice installs with npm and Bob with pnpm, they will not share a graph.

```bash
# CI: install exactly the lockfile, do not rewrite it
npm ci
yarn install --frozen-lockfile
pnpm install --frozen-lockfile
```

If you migrate managers, delete the old lockfile, install with the new tool, commit the new file.
