**Plug’n’Play** is Yarn Berry’s default linker. There is often **no** `node_modules`. Node asks `.pnp.cjs` (and `.pnp.data.json`) where each package lives — usually inside `.yarn/cache` zips.

```yml
# .yarnrc.yml — opt out of PnP, get a classic folder
nodeLinker: node-modules
```

```js
// tools that do this break under PnP
import fs from "node:fs";
fs.readdirSync("node_modules"); // folder may not exist
```

Editors need the Yarn SDK / PnP plugin so “Go to definition” works. Many teams keep Berry but set `nodeLinker: node-modules` for compatibility.
