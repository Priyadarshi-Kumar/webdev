A **Server Component** runs on the server (or at build time). It can `await` a database or file. It sends UI to the client. It **cannot** use `useState`, `useEffect`, or browser APIs.

```tsx
// Server Component (no "use client")
export async function PostList() {
  const posts = await db.posts.findMany();
  return (
    <ul>
      {posts.map((post) => (
        <li key={post.id}>{post.title}</li>
      ))}
    </ul>
  );
}
```

A file with `"use client"` is a Client Component. That is where hooks live. Pass data down as props; do not fetch in `useEffect` if a Server Component can do it.

This site’s pages are prerendered; interactive bits (theme toggle, tools) are client components.
