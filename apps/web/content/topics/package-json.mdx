`package.json` is the project manifest. Humans edit it. The lockfile is the machine-exact copy of what got installed.

```json
{
  "name": "web",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vike dev",
    "build": "vike build"
  },
  "dependencies": {
    "react": "^19.2.8"
  },
  "devDependencies": {
    "typescript": "^5.9.0"
  }
}
```

- `dependencies` — needed to run the app (React).
- `devDependencies` — needed to build/test (TypeScript).
- `scripts` — `npm run dev` / `pnpm dev`.
- `^19.2.8` is a **range**, not a pin.
