**Nx** sits next to your [package manager](/blog/package-manager). pnpm installs libraries. Nx **runs jobs** (`dev`, `build`, `test`) across many packages and remembers results.

```bash
pnpm nx build web          # one project
pnpm nx run-many -t test   # every project that has "test"
pnpm nx graph              # open the dependency map
```

This site’s root `package.json` scripts are thin wrappers: `"build": "nx build web"`.
