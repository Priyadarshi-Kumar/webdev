The **host** is the app you sit in — Cursor, Claude Desktop, VS Code Copilot Chat, a custom agent. It starts [MCP clients](/blog/mcp-client), shows tool-call approvals, and decides what the model is allowed to see.

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "./"]
    }
  }
}
```

That config lives on the **host**. The model never launches processes by itself.
